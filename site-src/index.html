Why the numbers changed. A public card service queries GitHub with its own token, so it can only ever see public repositories. Most of these commits are private. Rendering under a personal token counts that work — private repositories are ranked here, but never named.

There is no server. GitHub Actions renders the SVGs on a schedule and publishes them; this host only returns files. That is why it costs nothing, and why no one else's traffic can ever load it into the failure that took down the originals.
